# Node.js Native Test Runner (`node:test`) — v20–v22 Specialization

Node.js v20+ and v22+ LTS include a native, zero-dependency test runner with subtest hierarchies, mock timers, and native TypeScript type-stripping support.

---

## 1. Core Architecture & API

Import exclusively from `node:test` and `node:assert/strict`:

```typescript
import test, { describe, it, before, beforeEach, after, afterEach } from "node:test";
import assert from "node:assert/strict";

describe("DistributedSessionCoordinator", () => {
  let tempState: Map<string, number>;

  beforeEach(() => {
    tempState = new Map();
  });

  it("commits monotonic sequence numbers without drift", async (t) => {
    // Nested subtests with independent contexts
    await t.test("sub-operation: increment lease counter", () => {
      tempState.set("lease", 1);
      assert.equal(tempState.get("lease"), 1);
    });

    await t.test("sub-operation: reject non-monotonic rollback", () => {
      assert.throws(() => {
        if (tempState.get("lease")! <= 0) throw new Error("Invalid state");
      });
    });
  });
});
```

---

## 2. Mock Timers & Spies in `node:test`

Node 20+ provides built-in mocking utilities through the test context or top-level `mock`:

```typescript
import { mock } from "node:test";

test("handles timer expiration deterministically", (t) => {
  t.mock.timers.enable({ apis: ["setTimeout", "setInterval", "Date"] });

  let expired = false;
  setTimeout(() => {
    expired = true;
  }, 5000);

  t.mock.timers.tick(4999);
  assert.equal(expired, false);

  t.mock.timers.tick(1);
  assert.equal(expired, true);

  t.mock.timers.reset();
});
```

## 3. Node 22+ Type Stripping Execution

In Node 22.6.0+, run test suites directly with native TypeScript stripping:

```bash
node --experimental-strip-types --test test/**/*.test.ts
```
