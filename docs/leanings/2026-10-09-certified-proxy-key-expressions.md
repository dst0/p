# 2026-10-09 — Resolve certified proxy keys in the parent

- **Status:** Local regression passes; full certified comparison remains unverified.
- **Symptom:** A selected P/Pi provider can use supported `$ENV_VAR` or `!command` API-key expressions. Certified proxy setup treated the expression itself as the upstream bearer token, so authenticated startup and task requests would fail.
- **Root cause:** `readCertifiedProxyConfig` copied the raw `models.json` `apiKey` into the parent-owned proxy without applying the resolution semantics used by `ModelRegistry`. Candidate environments intentionally do not inherit the caller's secret-bearing environment.
- **Fix:** Resolve the already parity-checked canonical expression once in the parent with `resolveConfigValueUncached`, then pass only the resolved value to the proxy. Missing or failing expressions stop before proxy startup with a generic error that does not echo the expression or value. Candidate configs still receive only the benchmark sentinel key.
- **Snapshot/declaration constraint:** Importing from `packages/coding-agent/src` passed the focused key test but broke the immutable benchmark snapshot. Directly importing `dist` passed the snapshot but broke source-authoritative declaration checks. Route through the existing benchmark runtime binding: it loads copied `dist` JavaScript and binds its types to source-only declarations. Both real snapshot and declaration regressions caught these mistakes.
- **Rejected approach:** Forwarding the expression or the real key into candidate configuration would break authentication or expose the credential in candidate state. Resolving inside each candidate would require granting credential/command access across the containment boundary.
- **Trust boundary:** `!command` is trusted operator configuration and runs synchronously in the benchmark parent with its environment, outside candidate sandboxing. Review `models.json` before certification; do not accept untrusted command expressions as benchmark input.
- **Regression:** `certified-proxy-key-resolution.test.ts` failed for environment and command expressions plus unresolved values before the fix, then passed. Existing projection tests cover sentinel-only copied configurations.
- **Follow-up:** Complete a live certified run with raw wire-model evidence and verify publication sanitization before claiming benchmark or release readiness.
